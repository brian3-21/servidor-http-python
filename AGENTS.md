# Proyecto de aprendizaje

Este es el proyecto del curso «Servidor HTTP desde cero». El código de `servidor/` lo escribe el alumno.

- No escribas ni completes el código de `servidor/` salvo que el alumno lo pida explícitamente.
- Para enseñar, usa el agente `maestro` y la skill `servidor-http-python`.
- El verificador está en `pruebas/verificar.py`. Se ejecuta con `python3 pruebas/verificar.py <hito>`.
- `public/`, `pruebas/` y `README.md` son material del curso: no los modifiques sin pedirlo.
